# v1.0.0 — publication reproducibility release

This release is the public, publication-oriented code snapshot derived from the completed Paper 2 computational repository.

It contains:

- all model/evaluation source code needed by the publication pipeline;
- publication/tuning/final-protocol configuration files;
- core scientific and pipeline tests;
- compact authoritative final result summaries;
- publication figure data and PDF figures;
- model and dataset provenance documentation.

It intentionally excludes:

- raw, processed, and split MovieLens data;
- local virtual environments and caches;
- historical development logs;
- internal repository-closure/audit machinery;
- superseded historical result versions;
- large intermediate/per-user artifacts that are not required to inspect the reported results.

The MovieLens 1M dataset must be obtained directly from GroupLens Research.
